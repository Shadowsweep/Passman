# Passman - Open Source Password Manager

## 🔒 Secure Your Passwords with Passman

Passman is an open-source password manager designed to help you store and generate strong passwords securely. Whether you need to manage multiple accounts or generate unique passwords on demand, Passman ensures your credentials remain safe and accessible only to you.

## 🚀 Features

✅ **Secure Storage** - Store all your passwords in browser itself .  
✅ **Password Generator** - Generate strong and customizable passwords instantly.  
✅ **User-Friendly Interface** - Simple and intuitive design for easy password management.  
✅ **Open-Source & Self-Hosted** - Full control over your data and security.  

## 📌 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/passman.git
   ```

## 🛠️ Usage as a Chrome Extension

1. Open Google Chrome and go to `chrome://extensions/`.
2. Turn on **Developer mode** (toggle switch at the top right corner).
3. Click on **Load unpacked**.
4. Select the `passman` folder where you cloned the repository.
5. The extension will now be installed, and you can start using it from the Chrome toolbar.
